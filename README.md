# Bienvenido a Uocraft
 
El mod creado por estudiantes de la Universidad 
de Oviedo para estudiantes de la Universidad de Oviedo.
 
## Características
El mod no tiene un propósito definido concreto, planeamos
añadir bloques, criaturas, mecánicas y estructuras segun lo
que se nos vaya ocurriendo y las proposiciones que recibamos.

## Contribuciones
Para contribuir puedes escribir una issue en 
nuestro [github](https://github.com/uocraftteam/uocraft/issues).

Las contribuciones pueden incluir ideas, mejoras de texturas, 
código nuevo, mejoras al código, reportes de bugs, arreglos de bugs, 
aportes a la documentación, etc.

Aunque el mod tiene como objetivo principal los estudiantes
de uniovi, se mantienen adicionalmente las traducciones al inglés.
El codigo tambien está escrito íntegramente en inglés porque lo consideramos
la mejor práctica.
